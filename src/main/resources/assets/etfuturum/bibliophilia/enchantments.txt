# ============================================================================
# Et Futurum Requiem - Enhanced Book texture mapping (refined for Minecraft 1.7.10)
# ----------------------------------------------------------------------------
# SOURCE: Bibliophilia resource pack. The upstream data targets Minecraft 1.16.1
# and 1.21.x, so it is written around *modern* enchantment keys (Enchantment
# registry ids) and Fabric/Forge mod enchantments that mostly do not exist here.
# This file is the refined port: it keeps every texture, but the meaning of each
# line is defined for this mod:
#
#   Format:  <key>  TAB  <texture-sub-path>
#
#   <key>              Enchantment lookup key.
#                      * NO colon      -> a vanilla/backported enchantment, using
#                        the modern name this mod targets (e.g. harvest "digging"
#                        on 1.7.10 resolves to the "efficiency" entry here). The
#                        runtime match is done in EnchantedBookTextureHandler.
#                      * "modid:name"  -> third-party linkage: kept so that when a
#                        mod registers an enchantment whose name matches, the book
#                        uses that sprite automatically. Harmless when absent.
#
#   <texture-sub-path> Path of the sprite under assets/etfuturum/textures/items/.
#                      "vanilla/<name>" resolves to book_vanilla/<name>.png; any
#                      other "owner/<name>" (a third-party mod) resolves to
#                      book_mods/<owner>_<name>.png. The PNG files were renamed
#                      accordingly when unpacking Bibliophilia.
#
# [vanilla] section lists the full modern vanilla set (backport targets); only the
# ones actually registered (1.7.10 vanilla + frost_walker/mending/swift_sneak)
# are produced in-game. [mod] section is kept in full for auto linkage.
# ============================================================================
